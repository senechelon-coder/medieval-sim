# Worldly Life

A portrait-mobile, text-driven medieval life simulator built in Godot 4. Live an ordinary life, build a dynasty, trade between settlements, or brave dangerous routes as a merchant or pirate while the wider world evolves independently. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the project architecture and development phases.

**Current status:** Phase 2 is complete. The game now includes character creation and early-life progression, save/load, multiple local settlements and provinces, named nearby characters with independent lifecycles, relationships and local activities, dynasty identity, changing settlement conditions, and data-driven choice events. Phase 3 will introduce occupations and the first regional economy.
