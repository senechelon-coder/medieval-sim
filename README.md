# Worldly Life

A portrait-mobile, text-driven medieval life simulator built in Godot 4. Live an ordinary life, build a dynasty, trade between settlements, or brave dangerous routes as a merchant or pirate while the wider world evolves independently. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the project architecture and development phases.

**Current status:** the original vertical slice is complete — Phase 5's exit criterion is met. The game includes character creation and early-life progression, save/load, multiple local settlements and provinces, named nearby characters with independent lifecycles, relationships and local activities, dynasty identity, changing settlement conditions, data-driven choice events, occupations with wages and experience ranks, a regional market with per-settlement prices/stock and a peddler → caravan → ship trade-tier progression, multi-day travel with day-by-day road events and empire-appropriate bandit/pirate encounters, and a war system: a historically-grounded rival empire, a war that progresses in the background whether or not the player gets involved, occupation-aware recruitment, and a text-resolved battle with narrated beats, choices, and an outcome that feeds back into the war. Deeper content beyond each phase's exit bar (caravans, crewing a ship, piracy as a career, NPC succession, territory actually changing hands) remains ahead.
