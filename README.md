# Worldly Life

A portrait-mobile, text-driven medieval life simulator built in Godot 4. Live an ordinary life, build a dynasty, trade between settlements, or brave dangerous routes as a merchant or pirate while the wider world evolves independently. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the project architecture and development phases.

**Current status:** Phase 4's exit criterion is met. The game now includes character creation and early-life progression, save/load, multiple local settlements and provinces, named nearby characters with independent lifecycles, relationships and local activities, dynasty identity, changing settlement conditions, data-driven choice events, occupations with wages and experience ranks, a regional market with per-settlement prices/stock and a peddler → caravan → ship trade-tier progression, and multi-day travel between settlements with day-by-day road events and bandit/pirate encounters. Deeper Phase 4+ content (caravans, crewing a ship, piracy as a career) and Phase 5 (battles, wider-world independence) remain ahead.
