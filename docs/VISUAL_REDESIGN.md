# Visual Redesign Plan

## Context

The current black-and-gold theme is applied too uniformly. Nearly every
screen is dark panels, gold borders, centered labels, and stacked text. The
result feels more like a functional prototype database than a living
medieval world.

Main visual problems:

- Too many similar rectangular panels
- Gold is used almost everywhere, so nothing feels especially important
- Large amounts of plain text without portraits, objects, maps, or scene imagery
- Screens lack distinct visual identities
- Information hierarchy is weak
- Bottom navigation feels utilitarian
- Events do not feel dramatic enough
- Markets, travel, relationships, and war look like variations of the same menu
- Limited motion and environmental atmosphere
- Character portraits are symbolic rather than emotionally engaging

We should keep the established theme, but evolve it.

## Recommended visual direction

Keep:

- Black and dark brown foundation
- Aged gold framing
- Existing Worldly Life logo
- Medieval typography
- Portrait-phone composition

Add:

- Warm parchment and painted-scene panels
- Realm accent colors
- Illustrated character portraits
- Location artwork and regional maps
- Distinct icons for stats, goods, occupations, and actions
- More green, red, blue, bronze, and parchment highlights
- Layered cards with depth instead of identical outlines
- Stronger visual states for danger, opportunity, wealth, health, and war
- Subtle particles, candlelight, dust, smoke, and moving map markers
- Event cards that feel like illustrated story moments

Each area should feel different:

- **Life**: portrait, family, timeline, warm domestic atmosphere
- **World**: map-first, regional colors, settlements and routes
- **Activities**: illustrated action categories
- **Market**: goods, inventory slots, price arrows and colored supply indicators
- **Travel**: route progress, landscape art, danger status
- **War**: banners, heraldry, red accents, army strength
- **Battle**: large scene illustration, clear opposing forces, dramatic choices
- **Character**: portrait-first identity sheet with traits and family emblems

The right next step is not another simulation feature. It is a visual-system
pass beginning with one representative screen — probably the Life screen —
until we establish a richer style that can be reused everywhere. We should
redesign only that screen first, compare it with the current version, and
lock the direction before applying it across the game.

## Refined direction

This is a much stronger visual direction: the game should feel like an
illustrated medieval strategy interface rather than stacked black menus,
not simply "more decoration."

What we should preserve:

- Worldly Life identity
- Aged gold detailing
- Medieval typography
- Existing simulation and navigation
- Realm-specific cultural presentation

What we should adopt:

- Parchment information surfaces
- Carved wood and bronze framing
- Illustrated regional map as the central visual focus
- Large character portrait and identity card
- Compact top resource bar
- Illustrated event windows layered over the world
- Icon-led statistics
- Color-coded health, wealth, standing, danger, and choices
- Large physical-looking Age Up control
- Heavier, more tactile bottom navigation
- Visual separation between Life, World, Activities, Character, and More

Because the game is portrait-mobile, this style should be translated rather
than copied from any landscape-oriented reference literally.

## Step-by-step visual rebuild

1. **Life-screen foundation**
   - New wood/parchment frame
   - Compact top status bar
   - Portrait-first character card
   - Stronger health, wealth, standing, trait, and occupation presentation
   - Improved chronicle
   - Tactile Age Up and bottom navigation

2. **World presentation**
   - Illustrated vertical regional map
   - Settlement markers, routes, realm colors, and current-location marker
   - Expandable settlement information

3. **Event presentation**
   - Illustrated parchment event cards
   - Character/event artwork
   - Green, red, blue, and gold decision buttons
   - Clear consequences and danger indicators

4. **Activities and market**
   - Illustrated goods icons
   - Inventory slots
   - Price arrows and shortage/surplus colors
   - Occupation-specific panels

5. **Character and family**
   - Larger portrait
   - Dynasty emblem
   - Family portraits and relationships
   - Traits, culture, faith, and lineage presented visually

6. **Travel, war, and battle**
   - Route-progress presentation
   - Banners and army cards
   - Dramatic battle illustration
   - Strong red/steel visual accents

7. **Final consistency pass**
   - Responsive phone scaling
   - Consistent icons, frames, spacing, and typography
   - Touch animations and transitions
   - Performance and readability testing

We should begin only with Step 1: the Life screen. Once its composition
matches this vision, it becomes the visual template for every other screen.
No simulation systems are needed for this pass — it is UI/theme work only.
